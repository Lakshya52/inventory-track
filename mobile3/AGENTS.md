# mobile3 agent notes

Expo SDK 58 / React Native 0.88 / NativeWind 5 / Tailwind 4 app using Expo Router.

- Use `npx expo install <package>` instead of adding dependencies manually so versions match the SDK.
- Routes live in `src/app/`; components, hooks, services and theme live outside it.
- Font is **Lexend Deca** (`@expo-google-fonts/lexend-deca`), loaded in `src/app/_layout.tsx`.
- Check https://docs.expo.dev/versions/v58.0.0/ before using unfamiliar Expo APIs; do not rely on memory.
- Run `npx tsc --noEmit` and `npx expo lint` before declaring a task done.
- **Never start any server** (Expo/Metro, frontend or backend). The user starts all servers themselves.
- Android/iOS folders are generated by EAS/CNG — never hand-edit them.
